| 5 | Basic UI — file open/save/save-as, recent files, raw JSON editor, revert |
| 6 | Structured editors — player stats, currency, overview tab |
| 7 | Backup and history UI — backup list, restore from UI |
| 8 | Polish and release — localization (EN/DE), themes, CI/CD, multi-platform builds |
